# Zhanghao Li Academic Website

A dependency-free academic personal website designed for GitHub Pages.

## Deploy

1. Create a public repository named `Haoziworkshop.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub → Settings → Pages, set **Source** to **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://haoziworkshop.github.io/`.

## Structure

- `index.html` — homepage
- `research.html` — research agenda
- `publications.html` — verified publications
- `teaching.html` — teaching
- `cv.html` — web CV
- `about.html` — bio and contact
- `assets/css/styles.css` — visual system
- `assets/js/main.js` — mobile navigation

## Notes

The first version deliberately does not invent unavailable course titles, a portrait, Google Scholar URL, or a PDF CV. Add these once verified.
